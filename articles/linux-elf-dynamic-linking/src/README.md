# Source Code

This directory contains the source code used in the article examples.

Files:
- `hello_world.c`
- `hello_world_write.c`
- `libhacker.c`

From this directory's parent, run `make` to build all examples, or use individual targets such as `make hello_world`, `make hello_world_static`, `make hello_world_write`, and `make libhacker.so`.
